# Practice Makes Prepared

Toolkit from the NAGIC Monthly Meeting session (November 19, 2026) on creating ACGME mock site visits for programs and Sponsoring Institutions. Presented by Barbara Gohre and Kelly Conlon.

Site: https://behindgme.com/mock-site-visit-toolkit/

What is here
- `index.html`: the toolkit site. Fourteen fillable planning tools that save in the visitor's browser, with CSV, Markdown, and JSON export, plus the session guide and sources.
- `files/Mock_Site_Visit_Workbook.xlsx`: ten-sheet Excel workbook (scenario, six-week plan, ADS trace, document checklist, stakeholder scheduling, agenda, question bank, institutional themes, debrief tracker, mock calendar).

ACGME does not require mock site visits. A mock visit is a local practice. ACGME content comes from acgme.org; examples use the fictional NAGIC Medical Center. Free to copy and adapt.
